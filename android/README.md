# Brot for Android

The Android app for Solana Mobile and the Seeker. It is a WebView shell, generated by the Solana Mobile CLI
(`solana-mobile webshell`, 0.6.0), around the campaign site at <https://brot.markets/dev0x> on devnet. The site's code
is [`../app`](../app).

How the wallet connects: the shell appends `Solana Mobile Web Shell` to the WebView's user agent and hands
`solana-wallet:` intents to the wallet app. The site registers the Mobile Wallet Adapter for devnet
([`../app/features/wallet/register-mwa.ts`](../app/features/wallet/register-mwa.ts)), and inside the shell lists only
that wallet ([`web-shell.ts`](../app/features/wallet/web-shell.ts)). The wallet app on the phone opens a WebSocket on
the device itself, and the page connects to it, which the site's Content-Security-Policy allows (`ws://localhost:*`,
[`../app/next.config.ts`](../app/next.config.ts)).

The Kotlin and Gradle files are kept as the CLI generated them, so this folder builds the same app as the published
APK. Only `twa-manifest.json` changed: its signing key path is now a local file name instead of a path on one machine.

## Install

- **APK** (devnet, signed with a test key):
  <https://github.com/0x4cb-caramelo/Bakedtruth/releases/download/android-devnet-v0.1.0/brot-android-devnet-0.1.0.apk>,
  SHA-256 `8ffb28f06243a42e5697174a9d0785ed8cd23050b7be9f24a99a18f5b638d835`.
- **A wallet on the phone** that speaks the Mobile Wallet Adapter (Seed Vault, Solflare or Phantom), set to devnet,
  with test SOL from <https://faucet.solana.com>.
- In the app: **Connect**, then **Mobile Wallet Adapter**, then approve in the wallet.

## Build from a clean clone

You need JDK 17 and an Android SDK whose licenses are accepted (`sdkmanager --licenses`), with `ANDROID_HOME` pointing
at it. Gradle downloads the rest on the first build (Gradle 9.7.1, Android platform 37 and its build tools).

```bash
cd android
./gradlew assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

The debug build turns on WebView debugging, so `chrome://inspect` on a computer reaches the page inside the app.

## Release build

A release build is signed with the team's key, which is not in the repository. With the key file at
`android/brot-release.keystore` (ignored by Git) and its passwords in `SOLANA_MOBILE_KEYSTORE_PASSWORD` and
`SOLANA_MOBILE_KEY_PASSWORD`:

```bash
npx solana-mobile@0.6.0 webshell build android
```

The APK lands at `android/app/build/outputs/apk/release/app-release.apk`. Every later version must be signed with the
same key.

## Tested

On 2026-10-15 and 16, on an Android 15 emulator with the Solana Mobile test wallet (fakewallet) and the published APK:
Connect, then Mobile Wallet Adapter, the wallet asked to authorize Brot Markets on devnet, and the app came back
connected. Not yet on a Seeker.
